# 🎬 X (Twitter) & 810video 동영상 다운로더 (Chrome 확장 프로그램)

x.com(트위터) 및 **810video.com(PeerTube)**의 고화질 동영상(MP4) 및 GIF를 안전하고 편리하게 다운로드할 수 있는 **구글 크롬 확장 프로그램 (Manifest V3)**입니다.

---

### 🛡️ 100% 안전한 오픈소스 (악성코드 / 멜웨어 걱정 없는 이유)
웹 스토어의 일부 확장 프로그램들은 초기 배포 후 외부 제3자나 광고업체에 인수되면서 원격 추적 코드, 광고 인젝션, 정보 탈취형 악성 스크립트가 자동 업데이트로 삽입되어 삭제되는 경우가 많습니다.

본 확장 프로그램은:
- **순수 로컬 소스코드**: 원격 서버에서 스크립트를 다운로드하거나 실행하는 코드가 전혀 없습니다.
- **광고/추적 없음**: Google Analytics, 사용자 추적기, 쿠키 수집 코드가 일절 없습니다.
- **공식 CDN 직접 연결**: 트위터 공식 CDN(`video.twimg.com`) 및 810video 공식 스토리지(`810video.com/s3`)에서 원본 MP4를 브라우저로 직접 다운로드합니다.
- **개발자 모드(Load Unpacked) 로드**: 스토어 자동 업데이트로 인한 변조 위험 없이 사용자가 소스코드를 직접 소유하고 실행합니다.

## 🚀 설치 방법 (30초 완료)

1. **이 저장소 클론 또는 다운로드**:
   ```bash
   git clone https://github.com/valternt/X-downloader.git
   ```
2. **구글 크롬 브라우저**를 엽니다.
3. 주소창에 다음 주소를 입력하고 이동합니다:
   ```text
   chrome://extensions/
   ```
4. 오른쪽 상단에 있는 **`개발자 모드 (Developer mode)`** 토글 스위치를 켭니다.
5. 왼쪽 상단에 나타난 **`압축해제된 확장 프로그램을 로드합니다 (Load unpacked)`** 버튼을 클릭합니다.
6. 다운로드받은 `X-downloader` 폴더를 선택합니다.
7. 크롬 브라우저 상단 툴바(퍼즐 아이콘)에서 **X & 810video Downloader**를 고정(Pin)해두시면 더욱 편리합니다.

## 💡 사용 방법

### 1. X.com (트위터)에서 사용 시
- 동영상/GIF가 있는 트윗 하단 액션바(공유 버튼 옆)에 **`⬇ 다운로드 아이콘`**이 자동으로 표시됩니다.
- 아이콘을 클릭하면 해상도 선택 메뉴가 나타납니다:
  - 💎 **1080p Full HD** (최고 화질)
  - 🎬 **720p HD**
  - 📱 **480p SD / 360p**
  - 🔗 **동영상 URL 복사**
- 동영상 위에 마우스를 올려 우측 상단의 `⬇ 다운로드` 알약 버튼을 눌러도 다운로드할 수 있습니다.

### 2. 810video.com (PeerTube)에서 사용 시
- **동영상 재생 페이지**(`810video.com/videos/watch/...` 또는 `810video.com/w/...`)에 접속하면:
  - 비디오 플레이어 우측 상단에 **`⬇ 다운로드` 알약 버튼**이 표시됩니다.
  - 비디오 상세정보 하단에 **`⬇ 동영상 다운로드` 버튼**이 자동으로 추가됩니다.
- 클릭 시 사이트에서 제공하는 원본 고화질 MP4(720p, 480p, 360p 등)를 1클릭으로 바로 다운로드할 수 있습니다!
- (810video는 PeerTube 기반으로 관리자가 UI 다운로드 버튼을 숨겨둔 상태지만, 이 익스텐션이 백엔드 API를 통해 원본 MP4 링크를 직접 추출합니다.)

### 3. 확장 프로그램 팝업창 활용
- 크롬 우측 상단 확장 프로그램 아이콘을 클릭합니다.
- **감지된 동영상**: 현재 보고 있는 탭의 비디오 썸네일과 화질별 다운로드 버튼을 모아 볼 수 있습니다.
- **URL 입력**: X 트윗 링크나 810video 링크를 붙여넣고 [분석]을 누르면 즉시 다운로드할 수 있습니다.

## 🛠️ 확장 프로그램 없이 810video 다운로드하는 팁

1. **yt-dlp 터미널 다운로드** (가장 확실함):
   810video.com은 오픈소스 PeerTube 기반이므로 `yt-dlp`가 기본 지원됩니다.
   ```bash
   yt-dlp "https://810video.com/videos/watch/b01afdf9-f429-42ba-9431-b632b43efb99"
   ```

2. **주소창 API 변환 트릭**:
   - 주소의 `videos/watch/` 부분을 `api/v1/videos/`로 바꿔서 접속합니다.
   - 예: `https://810video.com/api/v1/videos/고유ID`
   - 화면에 표시되는 JSON 내용 중 `"fileDownloadUrl"` 주소를 복사해 주소창에 넣으면 바로 MP4 파일이 다운로드됩니다.
